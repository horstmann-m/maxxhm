# Roastmap — web app

The Next.js front end for Roastmap. See [`../ROASTMAP.md`](../ROASTMAP.md) for the
full project overview, architecture, and the Python knowledge pipeline.

```bash
npm install
npm run dev     # http://localhost:3000
```

- **User data** (notes, tastings, watchlist, preferences) lives locally in IndexedDB
  via Dexie — see `src/lib/db.ts`. No account needed; Dexie Cloud sync is opt-in.
- **Reference data** in `public/data/*.json` is generated by the Python pipeline in
  `../pipeline`; do not hand-edit it — edit the YAML sources and rebuild.

Deploy this `web/` directory to Vercel as a standard Next.js app.
